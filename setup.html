Adding it to OBS

  1. In OBS, click + under Sources and choose Browser.
  2. Paste a link from above into URL. Set width 1920 and height 1080 (or the size you want).
  3. Keep this server running while you stream. On Windows, start it with windows-server-start.bat.

Two overlays are available: Status overlay (camera, temps, progress, thumbnail) and 3D twin (the print growing live in 3D, transparent background).
